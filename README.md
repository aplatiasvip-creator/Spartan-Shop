# Spartan Shop

Καλώς ήρθες στο Spartan Shop, το community shop με ψηφιακά items, εικόνες προϊόντων και links προς τους creators.

## Περιήγηση

- Άνοιξε το `shop.html` για να δεις το shop.
- Χρησιμοποίησε τα φίλτρα **All**, **Supplies** και **Guns** για να βρεις προϊόντα.
- Οι κάρτες εμφανίζουν τιμή και διαθεσιμότητα. Τα **SharkAR** και **CKAR** είναι **Rare · Limited**.
- Οι σύνδεσμοι στην ενότητα Creators ανοίγουν τα TikTok προφίλ τους.

## Παραγγελίες

Οι παραγγελίες και η επιβεβαίωση διαθεσιμότητας γίνονται στο [Discord server](https://discord.gg/HUTU7tRQfZ). Το site δεν επεξεργάζεται πληρωμές ή κρατήσεις. Οι τιμές εμφανίζονται σε K, όπως έχουν δοθεί από το community.
